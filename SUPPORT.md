# PantryPin Support

PantryPin is an early public MVP maintained on a best-effort basis.

## Choose the right channel

- For setup questions and help understanding the project, use the [question form](https://github.com/nahin333/where-and-how-much/issues/new?template=question.yml).
- For reproducible defects, use the [bug report form](https://github.com/nahin333/where-and-how-much/issues/new?template=bug.yml).
- For product ideas, use the [feature request form](https://github.com/nahin333/where-and-how-much/issues/new?template=feature.yml).
- For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and report privately.

Before asking for help, read the [README](README.md), confirm that you are using Node.js 22, run `npm ci`, and search existing issues.

## Include useful context

When requesting help, include:

- whether you are using the GitHub Pages demo, local demo mode, or a self-hosted AI backend;
- your operating system, Node.js version, browser, and relevant commit or release;
- the exact command you ran and the complete sanitized error message;
- minimal reproduction steps;
- what you expected to happen.

Remove API keys, authorization headers, private image data, and personal information from screenshots and logs.

## Current limitations

The hosted GitHub Pages demo uses preset scenarios and does not analyze image pixels. Grocery prices, store distances, availability, and pickup times are simulated in all current modes. Nutrition output is an estimate and is not medical advice. Support cannot provide exact nutrition calculations, medical guidance, retailer-price guarantees, or private deployment administration.
